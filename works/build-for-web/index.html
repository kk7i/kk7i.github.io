Foundational Skills

数字创作者的基础技能 · 全景图谱

取自 Tyler Angert《Foundational Skills》全文 · 结合 2025–2026 AI 发展延伸
Editor's Brief

Angert 把过去 5–10 年最有用的技能归为 Computing、Design、Writing 三大域——它们互相补位，让一个人能从 0→1 快速把东西做出来。这不是线性课程，而是按优先级排序的能力地图：Computing 里，Web 是最高复利的选择；Design 里，信息设计是跨媒介的底层能力；Writing 里，写作即原型、类比即认知。三者交汇于同一个原则：先理解原语，再拥抱抽象。

紫色节点是把这套框架放到 2025–2026 AI 语境下的延伸：Vibe Coding 重写原型阶段，Prompt 成为新原语，Agents/MCP 重构工具链，但「判断力 > 生成力」的排序反而被强化——你越懂原语，越能驾驭 AI。点任意卡片，下方展开该节点的编辑解读。

① Computing 计算 · 6 节点

Web 是最高复利的选择；核心是理解原语（DOM、函数、数据建模），而非记住 API。

🌍 Why Build for the Web 原文

可移植、跨端、技能复利
  • 分发快、更新快，默认跨平台
  • 80–90% 项目可共用一个栈（如 React）→ 复利
  • 工具生态庞大、社区全球最大
  • 市场信号：WASM、协作应用常态化
  • 对比：Unity/Flutter 有各自优势，但 Web 便携性无出其右
→ HTML & CSS↔ Primitives↔ Vibe Coding

📐 HTML & CSS 原文

低门槛高天花板，一切 UI 的地基
  • 先学基础 HTML/CSS
  • Markup/styling 思维是通用语言（SwiftUI 同理）
  • SVG、CSS Animations 无需特殊工具即可试错
  • 「能在浏览器里直接 tinker」是 Web 最被低估的优势
← Why→ JavaScript↔ MCP↔ Primitives↔ Vibe Coding

⚡ JavaScript & DOM 原文

不靠库做原型，理解浏览器执行模型
  • 先无库做原型
  • 理解 DOM 是什么、如何操作
  • 理解浏览器如何执行代码（事件循环等）
  • 不依赖库也能做简单交互
  • 资源：Just JavaScript（Abramov & Appleton）
← HTML→ Framework↔ D3↔ Backend↔ Functions↔ Review

⚛️ 现代 UI 框架 原文

React / Vue / Svelte，选一个深入
  • 选一个：React / Vue / Svelte
  • 基础扎实后引入 TypeScript
  • 框架是抽象，不是捷径——顺序不能反
← JavaScript↔ MCP↔ Backend↔ Agents

🗄️ 后端基础 原文

进阶再说，深入必学
  • 基础数据建模
  • REST / GraphQL API 交互
  • WebSocket / Webhook 理解
  • Angert：工具变化快，先保前端基础
  • 数据库、realtime 属此范畴
↔ JS↔ Framework↔ MCP↔ Functions↔ BaaS

📊 数据可视化 原文

D3.js，需要时再学
  • 原文举例：D3.js
  • 建立在 JS + SVG 基础之上
  • 非独立阶段，属信息设计实践
↔ JavaScript↔ Agents

② Core Concepts 核心概念 · 2 节点

原文独立小节。一切系统 = 原语 + 抽象；一切过程 = 输入 → 函数 → 输出。这是贯穿所有域的元能力。

🧱 原语与抽象 原文

Primitives & Abstractions，元能力
  • 所有系统 = 原语（积木）+ 抽象（组合方式）
  • Lego: Bricks → Buildings；Music: Notes → Chords
  • 好抽象隐藏内部，让更多人可贡献
  • 能拆解问题 → 能设计好 API 与 UI
  • 不特定于 Web，但支撑一切
↔ HTML↔ JS↔ Framework↔ Backend↔ Functions↔ Prompt

🔄 函数与输入输出 原文

Functions & Input/Output，过程即变换
  • 函数 = 输入 → 处理 → 输出
  • Blender: fruits → smoothie；分类器: 图片 → 是/否
  • File I/O、Unix pipes、Client/Server、REPL 皆如此
  • 把目标建模为「输入 → 期望输出」的变换
  • Chatbot、搜索引擎、浏览器 URL 都是函数
↔ JS↔ Backend↔ Primitives↔ Writing↔ Prompt

③ Design & Writing 设计 · 写作 · 3 节点

信息设计是跨媒介的底层能力；写作是原型工具，类比是认知核心。Angert 反复强调：自然语言应与代码、草图并列为主要创作媒介。

🎨 视觉与信息设计 原文

Graphic, Visual & Information Design
  • 不必是视觉大师，但要懂基础
  • 现代 UI 设计基于图形 + 信息设计
  • 排版、留白、层级 = 写作中的分段与句式变化
  • 绘图、图解、草图是设计师的 table-stakes
  • FigJam、BioRender、Keynote 验证了可视化工具的市场
↔ Viz↔ Writing↔ Vibe Coding

✍️ 写作即原型 原文

Writing as a Tool，主要创作媒介
  • 写作用于原型、验证、完善想法
  • 功能常从 docs 甚至对话起步
  • 用箭头描述 user flow：event → event → back
  • 括号记号组织列表，结构即信息设计
  • 自然语言应与代码、草图并列
↔ Design↔ Analogy↔ Functions↔ Prompt

💡 类比思维 原文

Analogy，认知的核心
  • Hofstadter：类比是认知核心
  • 让抽象变具体（Make the abstract concrete）
  • Snapchat = 「会消失的拍立得」
  • ELI5 / 「像在派对上解释」
  • 去术语化 → 暴露思维漏洞
↔ Writing↔ Primitives↔ Prompt

④ AI 延伸 2025–2026 · 6 节点

把原文的「原型速度、写作即原型、工具链、后端进阶」放到 AI 语境下重写。虚线表示对应关系，非独立的第四条路径。

🎯 Vibe Coding AI

自然语言 → 功能代码，角色转为描述意图
  • Karpathy 2025 年提出
  • 从「AI 补全」→「Agent 自主多文件变更」
  • 核心循环：描述 → 生成 → review → 迭代
  • 工具：Cursor, Claude Code, Copilot Agent Mode
  • 需求清晰度 > 语法记忆
↔ Why↔ HTML↔ JS→ Prompt→ Agents↔ Review

📝 Prompt as Spec AI

写需求文档 = 新的核心编程技能
  • 不再只写函数，而是写 PRD / specs.md
  • Agent 需要清晰上下文与边界条件
  • 技巧：提供示例 > 描述规则
  • Plan Mode：先让 Agent 出计划，确认再执行
  • = Angert「写作即原型」的 AI 版验证
← Vibe↔ Review↔ Primitives↔ Functions↔ Writing↔ Analogy

🤖 AI Coding Agents AI

Cursor / Claude Code / v0，理解整个代码库
  • IDE 类：Cursor（Composer）、Windsurf（Cascade）
  • CLI 类：Claude Code
  • App Builder：v0、Bolt、Lovable、Replit Agent
  • 能力：读整个代码库、规划、写文件、跑测试、自修复
← Vibe↔ MCP↔ Review↔ Framework↔ BaaS

🔌 MCP & Context AI

Model Context Protocol，AI 连接工具与数据
  • MCP = Agent 的「USB 接口」
  • GitHub MCP：自然语言管仓库
  • Supabase MCP：用中文问数据库
  • Browser / Vercel MCP：截图验证 UI
  • 核心：上下文质量 > 模型聪明度
← Agents↔ Backend↔ Prompt↔ BaaS

🔍 AI Review & Debug AI

审查 AI 代码 = 新的核心竞争力
  • AI 擅长样板，弱于复杂业务 & 安全
  • 「最后的 20%」仍需人类把关
  • 调试成为主要摩擦点（不是写代码）
  • 工具：Sentry, OpenTelemetry, Chrome DevTools MCP
  • JS/DOM 基础 → 让你判断 AI 对错
← Vibe← Prompt↔ JS↔ Backend↔ Functions

☁️ BaaS & Edge AI

Supabase / Convex / Workers，后端托管化
  • Agent 最爱的后端 = 写 schema 就自动建库
  • Supabase：PostgreSQL + Auth + Storage
  • Convex：实时数据库 + 函数
  • Cloudflare Workers：边缘计算
  • 数据建模思维依然不可替代
↔ Backend↔ MCP↔ Agents
